info How to set up Google Drive Cloud Sync:
  1. Log into your target Google Account and open script.google.com → click "+ New project".
  2. Click "Copy Script Code" above, paste it into the Apps Script editor, and click 💾 Save.
  3. Select initialSetupAuth from the function list and click ▶ Run to grant Google Drive permission.
  4. Click Deploy → New deployment → Type: Web app (Execute as: Me, Access: Anyone) → Copy the Web app URL and paste into the box above.
